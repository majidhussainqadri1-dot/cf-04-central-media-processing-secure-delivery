# CF-04 Contract Drafts

These files are **pre-activation, non-runtime drafts**. They do not authorize media upload, processing, storage, delivery or data migration.

## Drafts

- `media-asset-reference.schema.json` — stable reference to an asset while preserving the owning domain’s canonical content truth.
- `upload-policy-envelope.schema.json` — domain-authorized technical limits, privacy class, scans, derivatives, delivery modes and retention rule for one upload purpose.

## Contract law

1. Draft version `0.1.0` is not a production contract.
2. Every affected domain owner must review the fields and state meanings.
3. Unknown contract versions fail closed.
4. Availability or successful schema validation does not grant authorization.
5. Internal tables, provider paths and credentials are not contract fields.
6. Privacy classification may be strengthened but not reduced by CF-04.
7. A policy envelope is immutable after use; changes create a new version.
8. Domain visibility, rights, consent, suspension, retention and object version are revalidated at action and delivery time.
9. No schema alone permits publication, clinical use, message access or public delivery.
10. Final contracts require Founder change control, compatibility tests, migration impact and rollback evidence.
