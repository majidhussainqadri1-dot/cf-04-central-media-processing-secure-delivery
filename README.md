## Release safety
The bundled local provider is limited to bounded in-memory assembly. Objects above the configured safe limit fail closed until an approved streaming assembly, scanning and delivery provider is installed and accepted on staging. This preserves the 1 GiB transfer contract without making an unsafe local-memory claim.
